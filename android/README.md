# Android 4.2+ 图片客户端

这是一个无第三方依赖、`minSdk 17` 的横竖屏自适应静态 PNG 客户端。用 Android Studio 打开 `android/`，使用 JDK 11+ 构建 debug APK；首次启动后长按画面，分别填入横屏、竖屏 HTTPS 帧地址和刷新秒数（建议 900）。

没有 Android 构建环境时，可直接在浏览器打开设备专属 `/viewer/<device>/<token>` 地址。该网页每十五分钟刷新一次图片，适合作为即时可用的轻量客户端。

客户端只下载图片，并把横屏、竖屏最后一张成功帧分别保存在应用内部目录。设备旋转后先立即显示对应方向的缓存，再尝试联网更新；断网、清理后台或重启应用时仍保留该方向上一张成功帧。客户端不会接触 Codex 凭据或 VPS 的数据写入令牌。

`0.2.1` 起使用适合墨水屏桌面的黑白线条启动图标；同一套多密度 PNG 资源兼容 KO1 Android 4.4.2 与 Bigme。

`0.3.0` 起支持旋转时自动切换横竖版地址与独立缓存。KO1 横屏使用 Oasis 1 帧，竖屏使用与物理分辨率一致的 KPW3 帧。

`0.4.0` 起会将当前方向的成功帧同步到外置存储的 `wallpaper/remote-eink-dashboard.png`。`0.4.3` 起在 KO1 上同时写入 Android 系统壁纸缓存，因此锁屏仍可显示看板，不依赖外置存储或 SuperSU。`0.4.4` 起该锁屏逻辑仅在 KO1 型号启用，并会把旧版单一地址同时迁移为横竖屏地址，确保 Bigme 从 `0.1.0` 直接升级后仍能显示原看板。`0.4.5` 起无网冷启动会静默显示上一张成功帧，不在画面上叠加拉图失败提示。
